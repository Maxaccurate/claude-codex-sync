# Changelog

## 0.3.2 — initial public preview

- Publish the Windows Claude ↔ Codex sync workflow under MIT.
- Add automatic discovery and explicit selection of Claude Desktop accounts for fresh installations.
- Capture saved changes with file events and queue updates while destinations are in use.
- Append both sides' visible messages with provenance markers and preserve original histories.
- Validate Codex paginated histories through the local app-server.
- Include backups, capture journals, isolated tests, and a Windows build workflow.

This preview does not guarantee instant UI refresh in active official clients. Unknown or rewritten histories pause synchronization.
